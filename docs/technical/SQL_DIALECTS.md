# Dialectes SQL

[← Portail](../INDEX.md) · [Guide SQL](../user/SQL.md)

Le MLD est dialecte-neutre. `SQLDialect` centralise citation des noms, types,
identités et particularités de rendu.

| Type MLD | PostgreSQL | SQLite | MariaDB/MySQL |
|---|---|---|---|
| `INTEGER` | `INTEGER` | `INTEGER` | `INT` |
| `BIGINT` | `BIGINT` | `INTEGER` | `BIGINT` |
| `DECIMAL(p,s)` | `DECIMAL(p,s)` | `NUMERIC` | `DECIMAL(p,s)` |
| `FLOAT` | `DOUBLE PRECISION` | `REAL` | `DOUBLE` |
| `BOOLEAN` | `BOOLEAN` | `INTEGER` | `BOOLEAN` |
| `VARCHAR(n)` | `VARCHAR(n)` | `TEXT` | `VARCHAR(n)` |
| `TEXT` | `TEXT` | `TEXT` | `TEXT` |
| `DATE` / `TIME` | `DATE` / `TIME` | `TEXT` | `DATE` / `TIME` |
| `DATETIME` | `TIMESTAMP` | `TEXT` | `DATETIME` |
| `TIMESTAMP` | `TIMESTAMP` | `TEXT` | `TIMESTAMP` |

## Identité

- PostgreSQL : `GENERATED BY DEFAULT AS IDENTITY` ;
- SQLite : `INTEGER PRIMARY KEY AUTOINCREMENT`, uniquement dans le cas inline
  compatible ;
- MySQL/MariaDB : `AUTO_INCREMENT`.

## Identifiants

PostgreSQL et SQLite utilisent les guillemets doubles ; MySQL utilise les
backticks. Les noms réservés sont cités et produisent un avertissement.

## Contraintes

PK, FK simples/composées, UNIQUE, CHECK et index viennent du MLD. Les actions
`ON DELETE`/`ON UPDATE` ne sont générées que lorsqu'elles sont renseignées.
Aucun `CASCADE` n'est inventé.

## Commentaires

PostgreSQL utilise `COMMENT ON COLUMN`, MySQL le commentaire inline et SQLite
un commentaire documentaire car il n'offre pas de métadonnée équivalente.

## Cycles

Le générateur ordonne le graphe des tables. Les cycles peuvent demander une
seconde phase `ALTER TABLE` lorsque le dialecte la permet. Les limitations de
SQLite sont signalées plutôt que masquées.
